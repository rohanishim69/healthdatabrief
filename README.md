# 🧬 My Health & Technology Intelligence Brief

Welcome to the GitHub repository for my weekly intelligence brief covering developments at the intersection of AI, biology, medical devices, public policy, and healthcare entrepreneurship.

## 🚀 Features
- **Responsive Layout:** Built using Tailwind CSS for clean desktop and mobile viewing.
- **Search & Filter:** Search stories dynamically in real-time.
- **Interactive Tracker:** Reflection modal for capturing notes on emerging careers.
- **Discussion Polls:** Interactive poll widgets for weekly ethics questions.

## 🛠️ Local Setup & Editing
1. Clone this repository.
2. Open `index.html` in any web browser.
3. Push changes to `main` to deploy via GitHub Pages.
